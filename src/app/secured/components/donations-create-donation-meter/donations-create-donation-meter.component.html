Spenderbarometer hinzufügen

Hier kann ein neuer Spenderbarometer erstellt werden. Gib dafür einen Titel, eine Beschreibung und ein Spendenziel an. Der Banner wird automatisch angezeigt und es entsteht ein Feld um den Titel des Spendenbanners als Spendenzweck zu verwenden. (Es können mehrere Spendenbarometer gleichzeitig aktiv sein.)
